2. Security Concerns
================================================================================

HIGH Severity
-------------

S1. pkg/server/localproxy.go:178-183
    InsecureSkipVerify: true — TLS verification disabled for mount proxying
    Impact: MITM attacks possible in production if this code path is reachable

S2. pkg/cache/server/options/options.go:102
    Cache server has no auth/z stack
    Impact: Any network-reachable client can read/write cached resources

S3. pkg/proxy/proxy.go:70-85
    Header values from user extra fields injected using url.PathEscape which
    doesn't sanitize for HTTP header context (newlines, null bytes)
    Impact: Potential header injection to downstream shards

S4. pkg/authentication/extra.go:55-64
    Default-allow extra field filter — keys not matching any deny pattern
    pass through unconditionally
    Impact: Sensitive authentication metadata may leak to downstream services


MEDIUM Severity
---------------

S5. pkg/proxy/proxy.go:87-102
    Reverse proxy director silent failure — sets host to "notfound" on
    missing shard URL, request continues processing
    Impact: Request may reach unintended endpoint; no error returned to client

S6. pkg/proxy/server.go:147-155
    Fake readyz/livez always returns OK
    Impact: Load balancer cannot detect unhealthy instances

S7. cmd/sharded-test-server/main.go:156
    Privileged group (system:masters) used to bypass entire authz stack
    Impact: Test server security model is fragile if exposed

S8. cmd/sharded-test-server/shard.go:96
    SA token lookup disabled
    Impact: Revoked/deleted service account tokens continue to work


LOW Severity
------------

S9.  pkg/authorization/deep_sar.go:113-116

     if context is corrupted

3. Performance Concerns
================================================================================

HIGH Severity
-------------

P1. pkg/admission/validatingadmissionpolicy/validating_admission_policy.go:259-261
    Discovery client + REST mapper created per workspace per admission call
    Impact: O(workspaces) API calls and memory allocations; dominates
    admission latency at scale

P2. pkg/server/options/options.go:400
    Watch cache disabled on cache server — every read hits etcd
    Impact: Etcd becomes bottleneck; reads don't scale; increased latency

P3. pkg/reconciler/core/logicalclusterdeletion/deletion/logicalcluster_resource_deletor.go:230-237
    Serial per-item deletion without batching or concurrency
    Impact: Cluster deletion time linear in resource count; can take hours
    for large workspaces

P4. pkg/informer/informer.go:738,756-757
    DeepCopy on every discovery request
    Impact: Memory churn proportional to API surface size x request rate

P5. pkg/reconciler/cache/cachedresources/replication/replication_reconcile.go:87-111
    N+1 GET pattern — individual Get() per replicated object
    Impact: Reconciliation time linear in object count; API server pressure
